# 仙途 · 苍玄界 — AI 修仙 MUD

由大模型（DeepSeek）实时演绎的沉浸式中文修仙文字游戏。你的一举一动都会改变这个世界——探索、修炼、战斗、拜师、炼丹、奇遇、寿元、轮回，全部由 AI 主控动态生成。

## 桌面版（EXE）与一键更新

- **桌面版**：`release/仙途苍玄界-1.0.0.exe`（便携版，双击即玩，无需浏览器与 Node 环境）。可直接发给朋友体验（朋友首次需在「设置 → 其他 → API 密钥」填入自己的 DeepSeek Key，或本机已有 opencode 凭证则免配置）。
- **存档位置**：`%APPDATA%\仙途苍玄界\data`（存档、快照、配置，升级不丢）。
- **设置系统**：上栏「设置」→ 画面（5 套皮肤/画面缩放/背景动画）、文字（叙事字号/面板字号/字体风格）、其他（API 密钥/一键更新/版本信息），全部即时生效并持久化。
- **一键更新（无需重新打包）**：
  1. 发布侧：修改后运行 `node make-update.js 版本号` → 生成 `update/update.json`
  2. 把 update.json 放到任意静态托管（GitHub Releases / 自有服务器 / 网盘直链）
  3. 把直链填入 `config.json` 的 `"updateUrl"`（桌面版可改 `%APPDATA%\仙途苍玄界\data\config.json`）
  4. 玩家（及收到 exe 的朋友）在「设置 → 一键更新 → 检查更新」→ 自动下载热更 →「重启生效」（≈网页刷新）
  - 前端资源（界面/样式/交互）走热更即时生效；游戏规则/服务器逻辑更新需要重新分发 exe（或更新后重启应用同样生效）。

## 快速开始

```bash
# 1. 配置 API Key
#    编辑 config.json，填入你的 DeepSeek API Key（https://platform.deepseek.com）
#    或设置环境变量 DEEPSEEK_API_KEY

# 2. 启动服务器（需要 Node.js 18+）
node server.js

# 3. 打开浏览器
#    http://127.0.0.1:8787
```

## 特色

- **AI 实时主控**：GM 世界观、境界体系、数值公平、天命骰全部写入提示词，每回合由 DeepSeek V4 Flash 即时演绎
- **完整修仙体系**：九大境界（炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫）、灵根、寿元、功法（黄/玄/地/天/仙阶）、丹药、法宝、符箓
- **道途与因果**：行为塑造流派（剑修/丹修/体修……），NPC 记仇报恩、伏笔回收、世界动态事件、多线结局
- **自由行动**：任何自然语言皆可——移动、探索、交易、拜师、偷窃、杀人越货，世界会真实回应（含后果）
- **探索性**：随机奇遇、秘境、洞府、悬赏、宗门任务；新区域随剧情展开，有风险梯度与未知迷雾
- **持久世界**：NPC、恩怨、任务、世界记事跨回合保持记忆
- **三档存档 + 快照回档**：每步操作自动存档；随时给进度命名存快照（每档 20 个），任意回档，回档前自动留「回档前自动备份」；导出/导入备份
- **完整人生记录**：大事记（突破/死亡/探索/任务）、完整指令与叙事日志，导出即全量迁移
- **真实死亡**：战死可复活（代价）或轮回转世（福缘+1、传承功法）；寿元耗尽即坐化
- **修为硬门槛**：修为达到当前境界所需即封顶，非突破不能再进（服务器强制，机缘丹药无法越界）；突破后清零重来，节奏稳扎稳打
- **属性与物品说明**：悬停属性/状态条/装备/背包/功法即可查看功用与恢复途径；GM 下发 item_ 说明自动入图鉴；剧情中描述过的物品会自动摘录「剧情见闻」原文展示
- **剧情记忆体系**：未了之事（伏笔/恩怨/承诺）登记回收闭环、长期记忆定期归档、台词自动存档——剧情前后连贯、伏笔可回收
- **任务即剧情**：重要剧情/奇遇/恩怨/秘闻以任务卡片展示（主线金/奇遇青/委托紫/悬赏橙/恩怨红/秘闻绿），完成即清除并载入大事件表
- **剧情监察**：关键节点自动由第二模型（v4-flash 同源）核查剧情连贯性，发现问题注入下回合让 GM 自然圆回
- **场景锚点**：GM 维护当前场景（在场 NPC/环境/气氛），快照常驻，场景连续不重启
- **天机问答**：右下角可拖动悬浮球「天机」，随时询问前文剧情（某人说过什么、去过哪里、恩怨缘由），只读人生档案、不耗回合
- **主角名讳**：留空由天命赐名，NPC 必以名相称；随时可改名（名字旁「改」）
- **剧情永久保留**：全部回合记录（含系统事件与场景标题）存档保留万回合量级，刷新后完整重放，滚动可见全程
- **新手引导**：首次进入自动弹出玩法说明与五步新手清单
- **水墨风界面**：深墨鎏金、大字号护眼，状态/功法/装备/行囊/任务面板实时刷新

## 时间系统（拟真 × 游戏性的平衡）

- **游戏内日历（青云历）**：服务器掌控时钟，GM 声明闭关/赶路/炼丹耗时（effects.time），服务器自动扣寿元、增年龄——闭关三月真有三月寿元的代价
- **剧情回合零等待**：战斗/对话/探索即时响应，只有有代价的长期行动才流逝时间
- **放置闭关**：底部「闭关修炼」→ 选时长（30分钟~7天），1 真实分钟 = 游戏 2 时辰，离线照常结算修为，出关时 GM 承接剧情；随时「提前出关」中断结算
- **寿元即压力**：寿元耗尽坐化是完整结局；突破延寿是最高奖赏

## 品控架构（三层）

AI 演绎类游戏最大的风险是"不可控"。本作把概率与数值全部收归服务器，模型只负责叙事表达：

1. **规则引擎层（确定性）**：境界只能升不能降、气血/灵力钳制、死亡/寿元判定、物品出入背包、存档原子落盘——全部由服务器代码强制，模型无法绕过。
2. **天命骰层（服务器掷骰）**：每回合由「存档种子 + 回合数」确定性生成机缘/凶险/变故三枚骰子（带福缘修正），随状态快照注入给 GM，GM 只负责按骰演绎——可复现、可审计、可验证，杜绝"模型自说自话掷骰"。
3. **叙事层（模型创作）**：自由度与文采所在，受 GM 规则约束（骰子相称、数值区间、反模板、实质推进、新手照拂）。

**保险丝**：GM 若越界（经验/灵石/物品超限），服务器自动截断并记入审计。
**审计日志**：`saves/audit/slotN-日期.jsonl` 记录每一回合的指令、骰子、effects、警告、规则版本——发现体验问题时回放即可定位，调参后对比版本即可验证效果。

## 存档体系

- 3 个档位，每档独立世界（`saves/slot{N}.json`）
- 每回合结束自动原子落盘，不怕断电丢进度
- 「存档」→「快照」：给任意时刻命名留档（如"筑基之前"），最多 20 个/档
- 「回档」：回到任意快照；回档前服务器自动把当前进度备份为「回档前自动备份」
- 「生平」：查看此生大事记；「导出/导入」：完整迁移（含日志与快照外的全部数据）

## 配置说明（config.json）

| 字段 | 说明 |
|---|---|
| `apiKey` | DeepSeek API Key。留空则自动复用本机 opencode 的 DeepSeek 凭证（无需重复配置） |
| `baseUrl` | OpenAI 兼容接口地址，默认 DeepSeek；换其他厂商改这里 |
| `model` | 模型名，默认 `deepseek-v4-flash`（官方另有 `deepseek-v4-pro` 更强者） |
| `port` | 端口，默认 8787 |
| `temperature` | 创作温度，0.9 左右兼顾稳定与文采 |
| `maxTokens` | 单回合输出上限，默认 4096；被截断会自动翻倍重试 |
| `useJsonMode` | 是否启用 JSON 结构化输出 |
| `disableThinking` | v4 系列思考模型的深度推理开关，默认关闭（更快更省） |

## 常用指令

移动：`向东` / `沿官道前行` / `回客栈`
修炼：`打坐` / `闭关` / `尝试突破`
战斗：`攻击妖狼` / `施放火球术` / `防御` / `逃跑`
交互：`与钱掌柜交谈` / `打听青云宗` / `购买聚气丹`
物品：点击右侧行囊，或 `服用聚气丹` / `装备玄铁剑`
其他：`查看四周` / `查看背包` / `查看状态` / `查看任务` / `帮助`

> 提示：不用记指令，游戏会给出可点击的快捷选项；一切自然语言都可以尝试。

## 项目结构

```
xiuxian-mud/
├── server.js          # 零依赖 Node 服务器（静态 + 游戏 API + 三槽存档 + 快照回档）
├── config.json        # 配置（模型/端口/温度；密钥自动复用本机 opencode 凭证）
├── game/
│   ├── gm.js          # GM 世界主控提示词（世界观/规则/数值铁律/道途因果）
│   ├── state.js       # 状态引擎：effects 结算、大事记、复活轮回、存档规范化
│   └── llm.js         # DeepSeek 调用（v4-flash 思考关闭、截断重试、容错解析）
├── public/            # 水墨风前端（大字号护眼）
├── saves/             # 存档与快照（自动生成）
├── test-engine.js     # 引擎回归自测（不消耗 API）
└── 启动游戏.bat
```
