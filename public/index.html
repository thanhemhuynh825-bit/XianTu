天道未连 · 需配置 API
游戏主控（GM）由 DeepSeek 大模型实时演绎，请先完成配置：

1. 打开游戏目录下的 config.json
2. 在 apiKey 一栏填入你的 DeepSeek API Key
3. 重启服务器（Ctrl+C 后重新 node server.js）
4. 也可以配置环境变量 DEEPSEEK_API_KEY，或直接复用本机 opencode 的 DeepSeek 凭证

获取密钥：https://platform.deepseek.com（价格极低，中文叙事一流）
闭关 · 放置修行
入定后真实时间开始流逝（1 真实分钟 = 游戏 2 时辰），游戏内时日与寿元随之消耗，修为按境界效率自动结算——关闭页面照常生效。

想收心时随时回来，点状态条「出关」即可中断结算。

悟性越高修炼越快（每点悟性 +2% 修为收益）——灵根与悟性决定你走得有多远。
仙途 · 修行须知
第一原则：这是一个完全自由的世界
「仙途」最大的亮点就是自由——AI 实时演绎的开放修仙世界，没有固定剧本、没有任务锁、没有"正轨"。你的每个选择都真实地改变命运。
可以苦修飞升，也可以开铺经商、种田务农、当官断案、四处游历、甚至摆烂到寿尽——每一种活法都会被世界认真回应。拒绝任务、背叛宗门、放人鸽子也都可以，只是会有真实的后果（NPC 记仇、江湖遗忘、悬赏高挂）。想说话就点输入框旁的 🎤 语音输入，说中文即可转文字。
初入此界的三个目标
① 活下去（妖兽、魔修、寿元都是威胁）　② 找到功法与修炼之道（打坐、拜师、坊市、奇遇）　③ 积累修为突破境界（炼气 → 筑基 → 金丹 → … → 飞升）。修为是硬门槛：圆满封顶，突破后清零重来，机缘无法越界。
怎么玩？
底部「言出法随」输入框直接打字行动，或点击快捷指令；右侧面板实时显示状态。
示例：向北 · 打坐修炼 · 与钱掌柜交谈 · 查看四周 · 服用聚气丹 · 攻击妖狼 · 逃 —— 任何自然语言都可以。
嘴懒？点输入框左侧的麦克风 🎤，直接说「向东走」「打坐修炼」，自动转成文字填入。
界面导览
上栏：地图（SVG 舆图，三级查看）/ 存档（快照回档）/ 万象（图鉴·人物志）/ 生平（大事件表）/ 设置（皮肤·字号·API·一键更新）
角色卡：头像下方有声名徽标（侠名/恶名，江湖对你的评价）与灵宠栏；属性格悬停可见每项的实际作用
面板卡：行囊 / 功法 / 因果（任务·未了之事·身外之物）/ 地理（状态·战况）四个分页，悬停任何属性或物品可查看说明
剧情页：每回合右下角「⤺ 回滚」可时光倒流重写命运
天机球：右下角可拖动的悬浮球，随时询问前文剧情（某人说过什么、去过哪里）
成长系统
属性都是真金白银：悟性每点 +2% 修炼效率（顿悟更多）；身法高者脱身先手更容易；福缘修正天命骰、奇遇更密——面板上的每个数字都在真实影响你的命运。
修炼：打坐/服丹/搏杀/奇遇 获得修为，圆满后突破。
天劫：金丹以上（含炼气→筑基）跨大境界突破必引雷劫——可以择日渡劫（先备法宝丹药、布阵、寻庇护），渡劫法宝替劫、宗门庇护化解皆算成功；失败则跌境重伤。
寿元：游戏内日历真实流逝（闭关三月真耗三月寿元），耗尽即坐化——时间是修行最大的敌人。
死亡：战死可复活（气血六成、损一成灵石）或轮回转世（福缘+1、传承功法）。
战斗与因果
战力森严：修为等级如天堑，NPC 登场会标注你可感知的战力情报；悬殊之敌正面必死——但智取之路无穷：偷袭陷阱、下毒借势、谈判化敌、借刀杀人，巧思可以直接改写胜负（同一招用第二次就不好使了）。
因果：NPC 有记忆会记仇报恩，重大抉择 3~10 回合内必有回响；伏笔会登记为「未了之事」督促回收。
限时任务：带 ⏳ 倒计时的任务「错过就没了」——世界言而有信，逾期会有真实后果。
声名：侠名/恶名影响 NPC 态度与事件（正道示好/悬赏通缉），但永远不锁死你的行动——行侠赎罪、金盆洗手皆可洗白。
灵宠：收服妖兽、结契灵兽可随行助战，养熟后是你最忠实的道友。
自由玩法：不止修仙
想换一种活法？世界接得住：种田（买田置地、春种秋收、灵稻值钱）、经商（低买高卖、开铺设店、行情随世界波动）、做官（科考/捐官/军功入仕，断案剿匪积治绩）、游历隐居（山可翻、水可渡，没有空气墙）。
你的田产、铺面、官职都会登记在面板「因果」页的身外之物里，随时可见、可经营、会卷入剧情（佃户闹事、官场倾轧、仇家烧店）。
存档与回档（重要）
每一步操作都自动存档，绝不丢进度。想保险起见：「存档」→ 选中档位旁的「快照」→ 给当前进度命名保存（每档 20 个）。任何时候可回档，回档前自动留「回档前自动备份」。剧情记录永久保留，刷新后完整重放。
